# Сервіс валідації якості ручної розмітки зображень

Автономний бекенд-модуль на чистій стандартній бібліотеці Python (`dataclasses`, `typing`, `math`, `json`, `pathlib`) для оцінки точності ручної розмітки у порівнянні з Ground Truth.

---

## 1. Архітектура та принцип роботи алгоритму

1. **Парсинг специфічної двоблочної структури:**
   - Перший блок містить загальні метадані кадру та опис фігур (`type`, `shape`).
   - Другий блок містить габаритні координати (`x1, y1, x2, y2`), атрибути поведінки (`oncoming` тощо) та контур багатокутника (`path`).
   - Об'єкти зшиваються між двома блоками за внутрішнім ідентифікатором `nm` у плоску структуру `UnifiedAnnotation`.

2. **Захист геометрії та крайові випадки:**
   - Функція `normalize_coordinates` запобігає інверсії осей, якщо координати введено у зворотному напрямку ($x_2 < x_1$ або $y_2 < y_1$).
   - Розрахунок перетину прямокутників захищений від вироджених фігур (нульова ширина/висота) та ділення на нуль при відсутності площі об'єднання.

3. **Жадібне парування за перекриттям ($IoU > 0$):**
   - Зіставлення фігур виконується суворо в межах однакового класу `type`.
   - Замість жорсткого порогу (наприклад, $0.5$), алгоритм зв'язує пари за будь-якого ненульового перекриття ($IoU > 0$) у порядку спадання перетину. Це дозволяє зафіксувати неакуратну розмітку (наприклад, $IoU = 25\%$) як пару зі зниженим балом, не створюючи штучного подвійного штрафу (одночасного False Positive та False Negative).
   - Об'єкти класифікуються як пропущені (FN) або зайві (FP) лише за повної відсутності геометричного перетину або відповідного класу на зображенні.

4. **Дворівнева метрика геометрії:**
   - **`bbox_iou`**: аналітична оцінка точності позиціонування та габаритів ($I / U \times 100\%$).
   - **`shape_score`** (оцінка якості форми контуру):
     - **Обидва об'єкти з `path`**: генерується бінарна растрова маска $64 \times 64$ через трасування променя (*Even-Odd rule*) з обчисленням точного піксельного IoU.
     - **Пара Polygon проти BBox** (коли розмітник деталізував форму контуром, а еталон заданий рамкою):
       - *Вписування точок (`containment_ratio`)*: частка вершин контуру, що потрапили в межі прямокутника (з допуском 2 px на похибку курсора).
       - *Щільність заповнення (`fill_ratio`)*: відношення аналітичної площі багатокутника за **формулою Гаусса (Shoelace formula)** до площі прямокутника.
       - *Двосторонній контроль меж (`Boundary Span`)*: перевірка охоплення крайніх точок $[x_{\min}, y_{\min}, x_{\max}, y_{\max}]$ відносно габаритів $W_{\text{gt}}$ та $H_{\text{gt}}$.
       - *Мультиплікативне масштабування*: базова оцінка форми множиться на коефіцієнт охоплення меж (`extent_factor`), що унеможливлює отримання пасивного бонусу при намальованій зменшеній фігурі чи втраті висоти/довжини об'єкта.
     - **Обидва BBox**: деформація відсутня, якість форми приймається за $1.0$.

    > **Примітка щодо оцінки Polygon проти BBox:**  
    > Оскільки еталонний JSON містить координати об'єктів у вигляді габаритних рамок без явного масиву `path`, порівняння контуру розмітника з BBox еталону є апроксимаційною інженерною евристикою на базі вписування точок та охоплення меж. За наявності векторних контурів у обох об'єктів або прямих бінарних растрових масок еталону алгоритм перемикається на точний піксельний IoU через `compute_raster_polygon_iou`.

5. **Зведена оцінка кадру (Overall Score):**
   $$\text{Score} = 0.30 \cdot F_1 + 0.30 \cdot \text{mIoU} + 0.25 \cdot \text{MeanShape} + 0.15 \cdot \text{AttrAcc}$$

   - **Обробка крайових випадків та відсутності збігів:**
     - Якщо розмітник не виявив жодного об'єкта ($TP = 0$) при наявності еталонів ($GT > 0$), показники форми та атрибутів повертають `0.0`, унеможливлюючи нарахування фіктивних балів за пропущені об'єкти.
     - Якщо кадр еталонно порожній ($GT = 0$) і розмітник також не додав жодної розмітки ($Pred = 0$), кадр оцінюється у $100\%$ як успішно розпізнаний True Negative.

## 2. Інструкція із запуску

Сервіс не потребує зовнішніх залежностей (`pip install` не потрібен).

### Запуск перевірки
Переконайтеся, що файли розмітки знаходяться у відповідних директоріях, та виконайте:

```bash
# Запуск валідації кадру
python annotation_validator.py

# Запуск набору модульних тестів
python test_validator.py
```
